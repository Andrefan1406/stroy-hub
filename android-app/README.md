# Android-приложение «VK Dev Транспорт»

Оболочка над сайтом (WebView): открывает страницу заказа служебного
транспорта `https://vkdevelopment.netlify.app/employee`. Вход — тот же, что
на сайте; заявки, правила и уведомления — на сайте и сервере, поэтому
приложение пересобирать нужно только при смене адреса, иконки или названия.

Свои страницы сайта открываются внутри приложения, остальное (Telegram,
звонок водителю, карты) — во внешних приложениях телефона.

## Сборка

Без Gradle, инструментами Android SDK (Git Bash):

    ./build-apk.sh                                  # адрес по умолчанию
    ./build-apk.sh https://<другой-адрес>/employee  # другой сайт

Результат — `build/apk/vkdev-transport-<версия>.apk`. Нужны JDK 17 и
Android SDK (platform 34, build-tools 34.0.0) — по умолчанию из
`%LOCALAPPDATA%\android-build`. Можно и обычным Gradle / Android Studio:
это стандартный проект.

Новая версия: увеличить `versionCode` (и `versionName`) в `app/build.gradle`.

## Ключ подписи

`%USERPROFILE%\.stroy-hub-android\` — `vkdev-transport.jks` и
`keystore.properties` с паролем. В репозиторий не попадают. Ключ нужно
сохранить (сделать резервную копию): обновление приложения ставится поверх
старого, только если подписано тем же ключом; потеряете ключ — придётся
удалять приложение у всех и ставить заново.
